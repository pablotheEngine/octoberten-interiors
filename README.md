# OctoberTen Interiors

Website for OctoberTen Interiors — premium bedsheets, throw pillows, duvets and bed sets.
Customers build a cart and send their order on WhatsApp (0703 220 9286). Delivery nationwide.

- `index.html` — the whole site (HTML, CSS and JavaScript in one file)
- `images/` — product photos

To host for free, enable GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
